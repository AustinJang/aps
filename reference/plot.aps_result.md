# Plot Method for aps_result

Default plot method showing performance over iterations.

## Usage

``` r
# S3 method for class 'aps_result'
plot(x, type = "performance", ...)
```

## Arguments

- x:

  An aps_result object

- type:

  Type of plot: "performance" (default) or "correlation"

- ...:

  Additional arguments passed to specific plot functions

## Value

A ggplot2 object
